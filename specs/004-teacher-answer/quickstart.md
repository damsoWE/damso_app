# Quickstart: 교사 답변 작성·점검·전송 (F4 교사)

## 준비

```bash
flutter pub get
flutter analyze
flutter test
flutter run --dart-define=USE_MOCK=true          # mock (서버 없이)
flutter run --dart-define-from-file=env/dev.json # 실서버 (Android 에뮬레이터 10.0.2.2)
```

mock 계정: F1 quickstart의 교사 계정 `teacher`(3학년 2반 담임). 데모 문의·본문 규칙은 [research R11](./research.md#r11-mock).
