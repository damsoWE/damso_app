# Quickstart: F5 확인 순서

```
flutter run --dart-define=USE_MOCK=true --no-enable-impeller       # mock
flutter run --dart-define-from-file=env/prod.json --no-enable-impeller  # 배포 서버
```

mock 계정 비밀번호는 모두 `damso1234`.
