# Quickstart: F2 검증 가이드

**Feature**: [spec.md](./spec.md) · 경로·화면: [contracts/routes.md](./contracts/routes.md) · API: [contracts/api-usage.md](./contracts/api-usage.md)

## 준비

```bash
flutter pub get
flutter analyze
flutter test
```

실행:

```bash
flutter run --dart-define=USE_MOCK=true                                              # mock (서버·Firebase 없음, 기기 알림 없음)
flutter run --dart-define-from-file=env/dev.json --dart-define-from-file=secrets/firebase.json   # 실서버 + 기기 알림
```

`secrets/firebase.json`은 git에 올리지 않는다. `secrets/firebase.example.json`을 복사해 Firebase 콘솔 값(프로젝트 ID·앱 ID·발신자 ID·API 키)을 채운다([research R10](./research.md#r10-firebase-설정-값-보관--원칙-viii와의-관계)). 이 파일이 없거나 값이 비어 있으면 기기 알림만 꺼지고 나머지는 동작한다.

## mock 데모 입력

## 자동 테스트로 확인하는 것

- 안내 화면 고르기·번호 정리 규칙 표 전체(data-model §1) · 모르는 코드
- 작성: 글자 수(이모지 포함 코드 포인트) · `Idempotency-Key` 재사용/교체 · 429 · 409 · 실패 시 내용 유지
- 교사 목록: 페이지 이어 붙이기 · 다시 불러오기 때 이전 목록 유지 · 홈 긴급 카드 조건
- 긴급 상세: 원문 호출 1회(다시 그려도 1회)
- 설정: 시작 ≥ 종료 · 빈 목록 = 항상 응답 가능 · 긴급 항목 없음
- 알림(가짜 `PushMessaging`): 열린 상태 수신 → 배너·목록 새로 고침, 알림 열기 → 경로, 로그아웃 → 해제 호출, 로그아웃 상태 → 로그인 뒤 이동
- 라우터: 탭 셸 경로 역할 검사, `/inquiries` 옛 경로, PendingNavigation
- 화면 글자에 `@`(이메일) 없음(교사 화면)
