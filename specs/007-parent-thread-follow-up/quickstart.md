# Quickstart: 학부모 스레드·이어서 묻기·답변 알림 — 배포 서버 E2E

mock 없이 배포 서버(`https://damso.jibang.site`)로 확인한다(R9).

## 준비

1. PR #25가 머지된 main으로 이 브랜치를 rebase했는지 확인(R2).
2. 워크트리에 git이 무시하는 파일 복사: `env/prod.json`, `secrets/firebase.json`.
3. Play 서비스가 있는 에뮬레이터(예: `Pixel_8`) 또는 실기기.
4. 테스트 계정: 같은 학급에 연결된 학부모 1명·담임 교사 1명. 비밀번호는 사람이 직접 입력한다.
5. 실행: `flutter run --dart-define-from-file=env/prod.json --dart-define-from-file=secrets/firebase.json`
6. 자동 검사: `flutter analyze`, `flutter test`.

교사 답변은 교사 앱(다른 기기) 또는 교사 토큰으로 `POST /api/v1/teacher/inquiries/{id}/answers`를 호출해 보낸다. 운영 DB에 테스트 문의·답변이 남으므로 본문 앞에 `[E2E]`를 붙인다.
