# Quickstart: F3 검증 가이드

**Feature**: [spec.md](./spec.md) · 경로·화면: [contracts/routes.md](./contracts/routes.md) · API: [contracts/api-usage.md](./contracts/api-usage.md) · 상태 전이: [data-model.md](./data-model.md#상태-전이)

## 준비

```bash
flutter pub get
flutter analyze
flutter test
```

실행:

```bash
flutter run --dart-define=USE_MOCK=true                    # mock (서버 없음)
flutter run --dart-define-from-file=env/dev.json           # 실서버 (F3 백엔드 배포 후)
```

새 패키지·설정 파일은 없다.

## mock 데모 문의 (교사 `teacher@damso.test`, 비밀번호 `damso1234`)

[research R10](./research.md#r10-mock--문의별-시나리오)의 표와 같다. 목록 제목은 서버가 정한 값(정리 중 / 원문 확인 필요 / 번역본 제목)이다.

| 학생 · 목록 제목 | 처음 상태 | 확인할 것 |
|---|---|---|
| 김하나 · 정리 중 (3시간 전 접수) | 정리 중 | 열면 정리 중 화면 → 다시 확인 → 번역본. 목록을 새로 고쳐도 열기 전에는 바뀌지 않는다. 원문 보기 뒤 돌아와도 상태를 다시 읽으므로(FR-018) 그때 번역본이 된다 — "다시 확인" 시연은 원문을 열기 전에 한다 |
| 김하나 · 정리 중 (2시간 전 접수) | 정리 중 | F2 데모. 교사 목록 두 번째 조회 때 정리 완료로 바뀐다 — F3 시연에는 3시간 전 문의를 쓴다 |
| 박서준 · 원문 확인 필요 (최근) | 재시도 가능 | 다시 정리하기 → F3-3a → 다시 확인 → 번역본 |
| 이도윤 · 원문 확인 필요 | 재시도 가능 | 다시 정리하기 → F3-3a → 다시 확인 → 버튼 없는 F3-3 |
| 박서준 · 원문 확인 필요 (이전) | 재시도 사용함 | 버튼 없음 + 한도 안내 |
| 이도윤 · 번역본 제목 | 정리 완료(정제) | 정서강도 높음 · 분노·답답함, 열고 나면 목록 단계 "교사 확인" |
| 김하나 · 번역본 제목 | 정리 완료 | 요청사항 없음 문구 · 라벨 없음 · 낮음 |
